# Distributed Compute Fabric

TA-IP-082 | Reference name: Ingrid

Assessment date: 2026-11-10

## Product overview

A distributed-compute product foundation for buyer-operated services.

Identified edition: 0.11.0

The 0.11.0 reference worker agent uses outbound-only operation over loopback TLS 1.3 mutual authentication, bounded reconnect, heartbeats and command/lease handling.
