04 / STATUS & BOUNDARIES

The present position

Current main baseline
Retained assessment-comparison build
Documentation reviewed
16 October 2026

The current source provides bounded multi-species site assessment, owner-scoped projects, sites and zones, versioned plan scenarios, retained assessment exports and read-only scenario comparison. The comparison report records 112 Go tests, seven Python regressions and 376 file-runtime checks. Earlier native PostgreSQL evidence applies to earlier retained-evidence source; the new comparison backend still needs its own native qualification. Regional data, live weather and deployment acceptance remain separate.

Material limitations

Botanical and spatial data coverage, real weather behavior and horticultural field accuracy need region-specific acceptance. The new comparison route is not covered by the earlier native database campaign.

Next qualification step

Run the exact comparison build against native PostgreSQL, then qualify regional botanical/spatial data, authorized weather behavior and the intended deployment.

Repository documentation and version records were reviewed for this catalogue. Product tests were not rerun. Retained seller handover grades, financial references and validation evidence keep their own dates and source scope; development candidates remain unmerged unless explicitly identified otherwise.
