# Plant Environment Decision Intelligence Platform

TA-IP-008 | Reference name: Florence

Assessment date: 2026-11-10

## Product overview

A plant-environment decision workbench for site suitability, versioned planting plans and evidence-backed comparison of retained assessments.

Identified edition: Retained assessment-comparison build

The implementation supports bounded multi-species site assessment, owner-scoped projects, sites and zones, versioned plans, assessment exports and read-only scenario comparison. The comparison report records 112 Go tests, seven Python regressions and 376 file-runtime checks. Native PostgreSQL acceptance for the comparison backend remains separate from evidence for other source editions.

## Potential acquirers

- Garden-planning software vendors
- Horticultural service firms

## Documented functions

- Assess several candidate species against one site
- Manage owner-scoped projects, sites and planting zones
- Retain versioned planting-plan scenarios
- Export assessment inputs, results and integrity records
- Compare retained scenarios and explain material differences

- Planning recommendations
- Data-quality records
